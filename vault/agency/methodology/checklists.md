# Checklists de funnel — F1.4 / F3.5 / F4.4 / F5.3

Los cuatro checklists de funnel del Manual Growth, listos para copiar a una tarea o usar en
revisión. El funnel se revisa en 4 momentos distintos con focos distintos: **diagnóstico**
(el de los competidores), **setup** (el propio, antes de lanzar), **lanzamiento** (cuando hay
clics sin conversión) y **optimización** (mejora continua).

## F1.4 — Diagnóstico: análisis del funnel de COMPETIDORES

- [ ] Landing pages: estructura, oferta, jerarquía
- [ ] Proceso de compra o registro (pasos, fricción)
- [ ] Llamados a la acción (dónde, cuáles, cuántos)
- [ ] Grabaciones y mapas de calor propios si hay acceso (Clarity / Hotjar)
- [ ] GA4: tiempo en página, rebote, conversiones — dónde se pierden los usuarios
- [ ] Eventos específicos con Tag Manager si hace falta medir clics puntuales
- [ ] Salida: lista de fricciones + buenas prácticas + oportunidades de conversión

## F3.5 — Setup: preparación del funnel PROPIO (gate para lanzar)

- [ ] Landing page principal
- [ ] Página de producto o servicio
- [ ] Proceso de compra o registro
- [ ] Llamados a la acción
- [ ] Optimización mobile
- [ ] Velocidad de carga
- [ ] Página de agradecimiento
- [ ] Seguimiento post conversión

## F4.4 — Lanzamiento: revisión cuando hay CLICS SIN CONVERSIONES

- [ ] Velocidad de carga de la página
- [ ] Claridad del mensaje
- [ ] Proceso de compra o registro
- [ ] Llamados a la acción
- [ ] Experiencia mobile
- [ ] Oferta presentada
- [ ] Página de agradecimiento
- [ ] Seguimiento post conversión

## F5.3 — Optimización: mejora CONTINUA del funnel

- [ ] Landing pages
- [ ] Proceso de compra o registro
- [ ] Llamados a la acción
- [ ] Claridad de la oferta
- [ ] Velocidad de carga
- [ ] Experiencia mobile
- [ ] Seguimiento post compra
